# Authentication API Documentation\n\nThis directory contains a comprehensive authentication API client for the ShueApp frontend, providing a complete interface to the backend authentication service.\n\n## Overview\n\nThe authentication API is organized into several modules:\n\n- **`index.ts`** - Core authentication functionality (login, register, token management)\n- **`verification.ts`** - Email, phone, and seller verification\n- **`middleware.ts`** - Authentication middleware, guards, and request interceptors\n- **`types.ts`** - TypeScript type definitions\n- **`login.tsx`** - Login-specific functions (backward compatibility)\n- **`register.tsx`** - Registration-specific functions (backward compatibility)\n- **`logout.tsx`** - Logout and auth state functions (backward compatibility)\n\n## Quick Start\n\n### Basic Authentication\n\n```typescript\nimport { AuthAPI, TokenManager } from '@/api/authentication';\n\n// Login\nconst loginResult = await AuthAPI.login({\n  email: 'user@example.com',\n  password: 'password123'\n});\n\nif (loginResult.success) {\n  console.log('Logged in:', loginResult.user);\n}\n\n// Register\nconst registerResult = await AuthAPI.register({\n  fullName: 'John Doe',\n  username: 'johndoe',\n  email: 'john@example.com',\n  phoneNumber: '+1234567890',\n  password: 'password123',\n  city: 'New York',\n  state: 'NY',\n  country: 'USA',\n  zipCode: '10001',\n  agreeToTerms: true,\n  marketingOptIn: false,\n  allowLocationPermission: true\n});\n\n// Logout\nawait AuthAPI.logout();\n\n// Check authentication status\nconst isLoggedIn = TokenManager.isLoggedIn();\nconst user = TokenManager.getStoredUser();\n```\n\n### Token Management\n\n```typescript\nimport { TokenManager } from '@/api/authentication';\n\n// Get tokens\nconst accessToken = TokenManager.getAccessToken();\nconst refreshToken = TokenManager.getRefreshToken();\n\n// Validate token\nconst validation = await TokenManager.validateToken();\nif (validation.valid) {\n  console.log('Token is valid:', validation.user);\n}\n\n// Refresh token\nconst refreshResult = await TokenManager.refreshAccessToken();\nif (refreshResult.success) {\n  console.log('Token refreshed');\n}\n```\n\n### Verification\n\n```typescript\nimport { VerificationAPI } from '@/api/authentication';\n\n// Verify email\nconst emailResult = await VerificationAPI.verifyEmail('verification-token');\n\n// Verify phone\nconst phoneResult = await VerificationAPI.verifyPhone('user-id', '123456');\n\n// Resend verification\nconst resendResult = await VerificationAPI.resendEmailVerification('user@example.com');\n\n// Get verification status\nconst status = await VerificationAPI.getVerificationStatus();\n```\n\n### Authentication Middleware\n\n```typescript\nimport { AuthMiddleware, AuthGuard } from '@/api/authentication';\n\n// Make authenticated requests\nconst profileData = await AuthMiddleware.authenticatedRequest('/auth/profile');\n\n// Check authentication in components\nif (AuthGuard.isAuthenticated()) {\n  const user = AuthGuard.getUser();\n  console.log('Current user:', user);\n}\n\n// Protect routes\nif (!AuthGuard.requireAuth()) {\n  // User will be redirected to login\n  return;\n}\n\n// Check roles\nif (AuthGuard.hasRole('admin')) {\n  // Admin-only functionality\n}\n\n// Setup automatic token refresh\nAuthMiddleware.setupAutoRefresh();\n```\n\n## API Reference\n\n### AuthAPI Class\n\nMain authentication operations:\n\n- `login(credentials: LoginRequest): Promise<LoginResponse>`\n- `register(data: RegisterRequest): Promise<RegisterResponse>`\n- `logout(): Promise<{success: boolean; message: string}>`\n- `changePassword(data: ChangePasswordRequest): Promise<{success: boolean; message: string}>`\n- `forgotPassword(email: string): Promise<{success: boolean; message: string}>`\n- `resetPassword(data: ResetPasswordRequest): Promise<{success: boolean; message: string}>`\n- `getProfile(): Promise<ProfileResponse>`\n- `getVerificationStatus(): Promise<VerificationStatusResponse>`\n\n### TokenManager Class\n\nToken and session management:\n\n- `getAccessToken(): string | null`\n- `getRefreshToken(): string | null`\n- `getStoredUser(): JWTUserPayload | null`\n- `storeAuthData(token: string, refreshToken: string, user: JWTUserPayload): void`\n- `clearAuthData(): void`\n- `isLoggedIn(): boolean`\n- `refreshAccessToken(): Promise<TokenRefreshResponse>`\n- `validateToken(): Promise<ValidationResponse>`\n\n### VerificationAPI Class\n\nVerification operations:\n\n- `verifyEmail(token: string): Promise<{success: boolean; message?: string; error?: string}>`\n- `verifyPhone(userId: string, code: string): Promise<{success: boolean; message?: string; error?: string}>`\n- `initiatePhoneVerification(phoneNumber: string): Promise<{success: boolean; message?: string; error?: string}>`\n- `resendEmailVerification(email: string): Promise<{success: boolean; message?: string; error?: string}>`\n- `resendPhoneVerification(phoneNumber: string): Promise<{success: boolean; message?: string; error?: string}>`\n- `getVerificationStatus(): Promise<{success: boolean; verificationStatus?: UserVerificationStatus; message?: string}>`\n- `verifySeller(data: any): Promise<{success: boolean; message?: string; error?: string}>`\n- `getSellerVerificationStatus(userId: string): Promise<{success: boolean; status?: any; message?: string; error?: string}>`\n\n### AuthMiddleware Class\n\nMiddleware and request handling:\n\n- `requestInterceptor(config: RequestConfig): Promise<Response>`\n- `authenticatedRequest<T>(url: string, options?: RequestConfig): Promise<T>`\n- `getAuthState(): AuthState`\n- `setupAutoRefresh(): void`\n- `logout(): Promise<void>`\n\n### AuthGuard Class\n\nAuthentication guards and checks:\n\n- `isAuthenticated(): boolean`\n- `requireAuth(redirectUrl?: string): boolean`\n- `getUser(): any | null`\n- `hasRole(role: string): boolean`\n- `hasAnyRole(roles: string[]): boolean`\n\n## Error Handling\n\nAll API functions return structured responses with success/error indicators:\n\n```typescript\n// Success response\n{\n  success: true,\n  data: {...},\n  message: 'Operation completed successfully'\n}\n\n// Error response\n{\n  success: false,\n  error: 'Error message',\n  message: 'Detailed error description'\n}\n```\n\nNetwork errors are handled gracefully, and authentication errors trigger automatic token refresh attempts.\n\n## Configuration\n\nThe API uses environment variables for configuration:\n\n- `NEXT_PUBLIC_API_URL` - Backend API base URL (default: `http://localhost:3001/api`)\n\n## Security Notes\n\n1. **Token Storage**: Tokens are stored in localStorage. Consider using httpOnly cookies for production.\n2. **Automatic Refresh**: The middleware automatically refreshes expired tokens.\n3. **Request Interceptors**: All authenticated requests include proper headers and error handling.\n4. **CSRF Protection**: Ensure CSRF tokens are included in production environments.\n\n## Migration from Legacy Code\n\nThis new API maintains backward compatibility with existing code:\n\n```typescript\n// Old way (still works)\nimport { loginUser } from '@/api/authentication/login';\nconst result = await loginUser(credentials);\n\n// New way (recommended)\nimport { AuthAPI } from '@/api/authentication';\nconst result = await AuthAPI.login(credentials);\n```\n\n## React Hook Integration\n\nFor React applications, you can create custom hooks:\n\n```typescript\nimport { useState, useEffect } from 'react';\nimport { AuthMiddleware, TokenManager } from '@/api/authentication';\n\nexport function useAuth() {\n  const [authState, setAuthState] = useState(() => AuthMiddleware.getAuthState());\n\n  useEffect(() => {\n    // Setup automatic refresh\n    AuthMiddleware.setupAutoRefresh();\n    \n    // Update auth state periodically\n    const interval = setInterval(() => {\n      setAuthState(AuthMiddleware.getAuthState());\n    }, 60000); // Check every minute\n\n    return () => clearInterval(interval);\n  }, []);\n\n  return authState;\n}\n```\n\n## Testing\n\nThe API is designed to be easily testable:\n\n```typescript\n// Mock the API for tests\njest.mock('@/api/authentication', () => ({\n  AuthAPI: {\n    login: jest.fn().mockResolvedValue({ success: true, user: mockUser }),\n    register: jest.fn(),\n    logout: jest.fn()\n  },\n  TokenManager: {\n    isLoggedIn: jest.fn().mockReturnValue(true),\n    getStoredUser: jest.fn().mockReturnValue(mockUser)\n  }\n}));\n```\n
